🤖 YourBot Widget Test Page

Production-Ready Chatbot Embedding

✅ Production Mode: Only ACTIVE bots can be embedded. Make sure your bot status is set to active in the dashboard.

How to Test:

  1. Create a bot in the dashboard and complete the onboarding
  2. Ensure the bot status is active (it should auto-activate after creation)
  3. Copy your bot ID or slug from the embed code in the Install step
  4. Replace YOUR_BOT_ID_OR_SLUG in the script tag below with your actual bot ID/slug
  5. Save this file and open it in your browser
  6. The widget should appear as a floating button in the bottom-right corner
⚠️ Important:
  • Your backend server must be running on http://localhost:8000
  • The bot must have status active to be embeddable
  • For production, replace localhost:8000 with your production API URL

Embed Code:

<script 
  src="http://localhost:8000/static/widget.js"
  data-bot-id="YOUR_BOT_ID_OR_SLUG"
  async>
</script>
